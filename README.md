# Рыночный дайджест в Telegram

Без ИИ и платных API. Работает на GitHub Actions. Данные: Банк России, Мосбиржа (ISS), Yahoo Finance, CoinGecko, smart-lab (дивиденды), RSS.

## Что приходит

| Когда | Что | Файл |
|---|---|---|
| Будни 07:40 МСК | Карточка дня (картинка) с подписью (сильные движения, повод для звонка, ⭐ ваш список) и кнопками: «Подробнее» (неделя вперёд, валюты, ставки, депозит vs облигации, рынки; по понедельникам — облигации недели), «Новости», «Денежные события», «Размещения» (на 14 дней вперёд), дашборд, «Сравнение», облигации. Кнопки открывают раздел «Сегодня» на дашборде прямо в Telegram. Графики за год — в «Подробнее», в раскрывающемся блоке внизу (отдельной картинкой больше не приходят). Подписи кнопок полные: длинные стоят по одной в строке, чтобы Telegram их не обрезал | `digest.py`, `charts.py` |
| Будни 10:05–18:05, каждый час | Алерт, только если что-то сдвинулось сильнее порога или ЦБ объявил решение по ставке | `alerts.py` |
| Пятница 19:30 МСК | Итоги недели + картинка для клиентов | `review.py` |
| Последний рабочий день месяца 19:45 МСК | Итоги месяца + картинка для клиентов | `review.py` |
| Всегда | Дашборд с графиками (GitHub Pages), обновляется каждое утро | `docs/index.html` |

GitHub запускает расписание с опозданием до 5–30 минут.

## Настройки

- **Даты заседаний ЦБ** — `CBR_MEETINGS` в начале `common.py`. Дополняй по календарю на cbr.ru.
- **Пороги «сильных движений» и алертов** — `MOVE_THRESHOLDS` в `common.py` (в %).
- **Подпись на картинке для клиентов** — Settings → Secrets and variables → Actions → вкладка *Variables* → `CLIENT_SIGNATURE`, например `Максим Дрягин · инвестиционный советник`.
- **Кнопка «Дашборд»** — переменная `DASHBOARD_URL` (адрес GitHub Pages). Пока её нет, кнопка не показывается.
- **Время дайджеста** — строка `cron` в `digest.yml` (время в UTC: МСК минус 3 часа).

## Дашборд (GitHub Pages)

Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/docs` → Save.
Через 1–2 минуты появится адрес вида `https://<логин>.github.io/<репозиторий>/` — его и записать в `DASHBOARD_URL`.
Графики появятся после первого запуска дайджеста (он создаёт `docs/data.json`).
Pages для **приватного** репозитория доступен только на платном тарифе GitHub. На бесплатном нужно сделать репозиторий публичным: секреты (токен и chat_id) при этом остаются скрытыми, в коде их нет.

## Проверка локально

`python digest.py --demo`, `python charts.py --demo`, `python review.py --period week --demo`, `python alerts.py --demo` — демо-данные, без отправки.
`DRY_RUN=1 python digest.py` — живые данные, печать в консоль.

Если источник не ответил, в логе запуска будет строка `[warn] …`, а в сообщении эта позиция просто пропадёт или будет «н/д».

## Ритм недели (автоматически)

- **Понедельник** — «Неделя впереди»: заседания ЦБ/ФРС, отсечки, аукционы ОФЗ, налоговый период, праздники.
- **Среда** — аукционы ОФЗ (если Минфин объявил). **Четверг** — недельная инфляция (заголовки новостей).
- **Накануне заседания ЦБ** — анонс. **В день заседания ~13:35** — флеш с решением (`flash.py`, `flash.yml`).
- **1/11/21 числа** — пометка о новой ставке по вкладам; **20–28** — налоговый период; **май–июль** — расширенный дивидендный календарь; **декабрь** — напоминания про ИИС и сальдирование.
- В нерабочие дни (список `RU_HOLIDAYS` в `events.py`) дайджест и алерты не отправляются (ручной запуск — отправит).

## Mini App в Telegram

Кнопки под дайджестом открывают страницы прямо внутри Telegram. Адреса — с параметром `?v=` (например `?v=CNY`, `?v=details`, `bonds.html?v=compare`): Telegram дописывает свои данные после «#», поэтому якоря в Mini App не работают.

На телефоне страница облигаций открывается на весь экран, жест «потянуть вниз» не сворачивает приложение, кнопка «Назад» Telegram возвращает на предыдущий экран (шторка → экран портфеля → «Сравнение»), кнопки отвечают лёгкой вибрацией. Нужна актуальная версия Telegram (Bot API 8.0+); в старой — обычный развёрнутый режим.

Вкладка «Сравнение» на дашборде (бывший калькулятор) и `?v=calc` открывают «Быстрое сравнение» на странице облигаций.

## Облигации: страница `bonds.html`

Четыре вкладки: **Старт · Портфель · Подбор · Разбор**. Справа в шапке — **«＋ Новый клиент»**: всё с нуля (сумма, срок, ставка вклада, портфель, закрепления, исключения), несколько секунд можно «Вернуть». Если со страницей не работали больше 4 часов — она сама начинает новый расчёт, а прошлый можно продолжить кнопкой «↩ Продолжить прошлый расчёт». «Очистить портфель» — в «Ещё…»; после очистки, пересборки, замены или удаления бумаги видна кнопка «Вернуть».

**Память.** Всё хранится только на устройстве и в том приложении, где открыта страница (телефон и ноутбук, Telegram и Safari — отдельно); на сервер ничего не уходит. Подпись для отчёта и сохранённые портфели «Новый клиент» не трогает; «Недавние» — в «Ещё…», на стартовом экране их нет, чтобы клиент не видел чужих сумм.

### Старт — «С чего начнём?»
- Четыре ситуации клиента: **🏦 Деньги на вкладе** (спрашивает ставку его вклада и показывает «Вклад недополучает X в год» по сравнению с «Консервативным»), **💸 Нужен доход в месяц** (сколько вложить в каждый вариант), **📂 Уже есть облигации** (вкладка «Разбор»), **💼 Разместить сумму** (варианты без упора на вклад; сравнение с вкладом — переключателем «🏦 Сравнить с вкладом»). После выбора плитки превращаются в строку переключателей.
- Сразу под ними — **«✍ Собрать портфель вручную»**: пустой портфель, строка поиска (эмитент, название, ISIN), подсказки лучших бумаг под срок и кнопка «Весь рынок — Подбор». Бумаги добавляются при клиенте одна за другой.
- Сверху: сумма (можно коротко: «50» = 50 млн, «1,5 млрд»; быстрые суммы), срок, счёт, ставка вклада (когда сравниваем с вкладом).
- Карточки: Только ОФЗ · Консервативный · Короткие ВДО (+ Умеренный и Доходный кнопкой). Каждый вариант — настоящий портфель из бумаг Мосбиржи тем же движком; в рублях, после НДФЛ: доход на руки, годовых, риск (для ОФЗ — «нет риска дефолта», для ВДО — ожидаемые дефолты и плохой сценарий, при сравнении с вкладом — шанс обогнать вклад), купоны в месяц, число бумаг и средний рейтинг. «Открыть» — портфель переходит в «Портфель».
- Ниже — **«Типовые портфели»**. На карточке видно «💴 можно добавить займ в юанях до X» (если в портфеле есть ОФЗ/валютные бумаги под залог). Галочки «сравнить» на двух карточках → «⚖ Сравнить два» — таблица рядом.

### Портфель (один экран)
- Сверху закреплена строка: **Сумма · Срок · Портфель · Счёт · ⚙**; каждая «таблетка» открывает выбор шторкой. Смена срока или портфеля пересобирает состав (📌 закреплённые бумаги остаются), смена суммы и счёта — пересчитывает.
- Порядок: итог («вложили → получите», плавно меняющиеся цифры и «± к прошлому варианту»), сравнение с вкладом и ОФЗ (с колонкой «сверх инфляции»), **Состав** (сворачивается), деньги по месяцам (переключатель «ближайший год на руки / весь срок»), запас прочности (свёрнут, в заголовке — шанс обогнать вклад), лесенка погашений, «Если ставки изменятся» (ползунок ключевой ставки и сдвиги ставок).
- На мониторе шире 1200 px — две колонки: слева состав, справа результат.
- Пояснения спрятаны за «i» и открываются шторкой; в PDF-отчёт попадают как раньше.
- Служебное убрано с глаз: проверка профиля и заметки по сборке — одной строкой «✓ В рамках профиля» (подробности по нажатию), таблица резкого сдвига ставок — в раскрывающемся блоке; на телефоне сравнение с вкладом и ОФЗ — карточками без обрезанных колонок.
- **Займ в юанях** — отдельная карточка в портфеле, если в нём есть бумаги под залог (ОФЗ, валютные): «можно занять до X под залог» → «Посчитать» → итог с займом, «▶ Показать с займом» и «Настроить займ». В «Составе» такие бумаги помечены «💴 залог».
- **Сравнить с другим портфелем** — ссылка «⚖» прямо в карточке сравнения с вкладом, а также в «Ещё…».
- На телефоне снизу закреплены «▶ Показать клиенту · Отчёт · Ещё…». В «Ещё»: займ в юанях, ссылка для клиента, сравнение с другим вариантом, отчёт, сохранить / открыть сохранённый, очистить.

### Состав
- Бумаги карточками (на телефоне без горизонтальной прокрутки): доходность, купон, погашение, доля «−/+», сумма и количество штук.
- **↻ похожая** — замена на бумагу того же типа купона, близкого рейтинга и срока, другого эмитента, с лучшей оценкой (повторное нажатие — следующий вариант).
- **📌 закрепить** — бумага остаётся при пересборке с той же долей.
- **Без отраслей**: чипы «Девелопмент», «Банки», «Лизинг», «МФО…» и отрасли из портфеля — портфель пересобирается без них (запоминается до очистки).
- Добавление бумаги — поиск с подсказками по эмитенту, названию или ISIN; карточка «Соответствие профилю» и «Структура» (отрасли, рейтинги, сроки, валюты, купон).

### Профили
- **Консервативный** — ОФЗ от 50%, остальное AA и выше, фикс. купон, дюрация до 3 лет, до 25% на отрасль.
- **Умеренный** — ОФЗ от 20%, от AA−, флоатеры до 30%, до 10% на эмитента, 30% на отрасль.
- **Доходный** — от A−, группа «A» до 40%, до 7% на эмитента, 35% на отрасль.
- **Только ОФЗ** — только госбумаги с фиксированным купоном (ОФЗ-ПК — флажком в ⚙), до 20% на выпуск (минимум 5 выпусков), сроки лесенкой равномерно до срока клиента. Если коротких ОФЗ мало — добавляются выпуски на полгода–2 года длиннее (в конце срока продаются по рынку), с предупреждением.
- **Короткие ВДО** — рейтинг строго BB+…A−, погашение/оферта до 1,5 года, цена от 95%, без метки «риск», без субординации и СФО, без дефолтов и техдефолтов в истории (эмитент исключается), объём выпуска от 500 млн ₽ (если Мосбиржа отдаёт объём), фиксированный купон, ликвидность от позиции, до 4% на эмитента (при нехватке эмитентов — до 6%), до 20% на отрасль, цель — 25+ эмитентов. Что не разложилось по правилам — в короткие ОФЗ как резерв. При сроке больше 1,5 года — предупреждение: деньги после погашения реинвестируются под доходность портфеля (допущение).
- Профиль «Агрессивный» убран (старые сохранения открываются как «Доходный»).

### Подбор
- **«Есть лучше»**: метка у бумаги, если есть альтернатива — надёжность не ниже, срок ±30% (не больше года), тот же тип купона, другой эмитент, доходность выше минимум на 0,5 п.п., без метки «риск», ликвидная (флоатеры не сравниваются — их доходность лишь оценка). При «+» в Подборе и при добавлении бумаги в «Составе» открывается окно: две бумаги рядом и «Взять лучшую» / «Оставить эту» («оставить» — подсказка для этой бумаги больше не появляется).
- Все облигации Мосбиржи без субординированных и СФО — всегда; бумаги с меткой «риск» — внизу; по одному лучшему выпуску на эмитента. Поиск с подсказками: эмитент → все его выпуски, бумага → сразу она, ISIN — точное совпадение.
- Фильтры сворачиваются («Фильтры (2) ▸», на телефоне свёрнуты по умолчанию), карта рынка — по нажатию.
- «Оценка» 0–100: доходность 35%, переплата к норме 25%, надёжность 25%, ликвидность 15%; нажатие на название — «Почему эта бумага» (шторкой) с вероятностью дефолта по рейтингу (Эксперт РА, 2001–2024).

### Разбор портфеля клиента
- Вставить бумаги (ISIN или название + сумма/шт/%) или найти через поиск — строка добавится сама. Проблемы (риск, ликвидность, >15% на эмитента, >35% на отрасль), замены той же надёжности и «сколько недополучает» в год.
- «Открыть как портфель», «Открыть с заменами», «⚖ Сравнить: как есть и с заменами». Ничего не сохраняется.

### Сравнение двух вариантов
Таблица рядом: получите на руки, доход, годовых, больше вклада на, шанс обогнать вклад, купоны в месяц, средний рейтинг, число эмитентов, наибольшая доля эмитента, выпусков; лучшее значение в строке — зелёным. Открывается со «Старта» (галочки на двух карточках), из портфеля («⚖ сравнить с другим портфелем») или из «Ещё…». Сравнить можно с любым профилем, сохранённым портфелем или портфелем клиента из «Разбора»; «Открыть этот» — переносит вариант в «Портфель».

### Презентация
- «▶ Показать клиенту»: итог → сравнение → «ваш портфель → наш» (если пришли из «Разбора») → запас прочности (для ОФЗ — «только государство») → зарплата от капитала → из чего состоит → **QR «Расчёт у вас в телефоне»** (клиент сканирует с экрана).
- Если займ посчитан, в основную презентацию добавляется слайд «А если добавить займ в юанях».
- Займ в юанях — отдельная презентация: свои → с займом, как работает плечо (схема), доходность на свои деньги без займа и с займом, **риски честно** (плавающая ставка и порог RUSFAR CNY, запас по обеспечению по упрощённой модели, курс), итог.

### Ссылки и отчёт
- **Ссылка для клиента** (`?p=…&cv=1`): упрощённый вид — итог, сравнение, деньги по месяцам, состав, запас прочности, лесенка и презентация; без редактирования, вкладок и подсказок для советника; рабочий портфель советника на устройстве не перезаписывается. Показывается QR и кнопка «Отправить в Telegram».
- **Ссылка для себя** — тот же портфель в рабочем виде. Имя клиента в ссылки не попадает; цены — на момент открытия; по ссылке позже видно «Как живёт портфель с …».
- **Отчёт / PDF** — одна страница A4 с QR. Внутри Telegram печати нет — «Открыть в браузере → PDF».

### Расчёты (без изменений)
- Доходность — по графику выплат Мосбиржи и цене предложения с НКД; после НДФЛ 13–22% (реформа 2027 — флажок в ⚙); ИИС-3 — без налога до 30 млн ₽ дохода, купоны на ИИС-3 остаются на счёте.
- Вклад — макс. ставка топ-10 банков (ЦБ) или ставка клиента, без капитализации, необлагаемая сумма процентов; переоформление — по ставке, которую закладывает кривая ОФЗ.
- Запас прочности — стресс по крупнейшим эмитентам (возврат 25%) и 10 000 симуляций дефолтов по рейтингу.
- Займ в юанях: под ОФЗ и валютные облигации с дисконтом 20%, ставка RUSFAR CNY + 4% / 3% / 2% по объёму счёта, на весь срок.

## Облигации в дайджесте (по понедельникам)

Блок «Облигации: итоги недели»: лучшие бумаги (переплата к норме рейтинга: AA–AAA, A, юани), первичные размещения (bonds-lab.ru), изменения рейтингов и дефолты за прошлую неделю. Бумаги — ссылки на подбор. Проверить в любой день: переменная `BONDS_WEEK` = `1`.

## Проверки

`node tests/bondmath.test.js` — математика облигаций (доходность, дюрация, выпуклость, налоги). Сверка с биржей на 519 реальных выпусках с известным графиком выплат: в 96% доходность совпала с Мосбиржей до 0,01 п.п., дюрация — до 2 дней. Расхождения — у валютных бумаг (до 0,15 п.п., биржа считает по своему курсу), у дисконтных (биржа показывает простую доходность, здесь — эффективная) и у флоатеров (биржа часто ставит неизвестные купоны в ноль).
